# 开局与流派

下表按当前原版 0.46D 的开局组织。流派是路线建议，可以混合。用 `game_starts` 读取当前客户端提供的开局、装备、说明和可用性。已有存档用 `game_shop` 的 `scenario`，实际装备以库存为准。

| 开局 | 核心循环 | 开局先核对 |
| --- | --- | --- |
| 学徒 `apprentice` | 基础倒卖、整理库存、顾客关系。适合作为混合经营底盘 | 合成肉、代糖果汁、牙膏、厕纸和储藏区。留出下次房租 |
| 水商 `water_merchant` | 取水、检测、过滤或净化、分装，面向需要饮水的顾客 | 纯度、实际可用容量、滤材、能量和瓶子，避免把未验证的水当高等级出售 |
| 销赃人 `fence` | 黑市高毛利、处理违禁或赃物、隐藏和分流库存 | 黑灯、藏货区、文件、买家意向，查治安与搜查状态 |
| 一贫如洗 `rock_bottom` | 低成本求生，先以小件周转和可领取奖励积累本钱 | 首次租金期限、可用现金、免费货源，确认有利润后再上设备 |
| 水培农场主 `hydroponic_farmer` | 种子、水、模块和能源转化为稳定产出 | 分开留种和卖出的份额，先用产出栏与植物分析判断瓶颈 |
| 枪械匠 `gunsmith` | 枪、弹药与配件的组装、修理、销售或交单 | 许可等级，原料与成品的弹药兼容性，枪匠订单中的实际需求 |
| 化学家 `chemist` | 扫描和混配、测量液体、加热或后处理、分装 | 化学指南、精确容量、混合液组成和合法性，核对批次而非猜测 |
| 养鼠人 `rancher` | 饲养、繁殖和屠宰，出售肉或供下游加工 | 动物的食物、容量、繁殖与健康，保留繁殖群和备用饲料 |
| 水产养殖户 `aquafarmer` | RAS 水循环养鱼、供氧和过滤、按阶段养成后取肉 | 水量、污染、供电、饲料及鱼的成长阶段，观察每晚变化 |

当前可用开局通过 `game_starts` 核对。经营中的具体功能以当前库存、配方和游戏面板为准。

跨路线还有估价行会、供应商与订单、夜间采购和拾荒、派系与治安、健康与成瘾、自动售卖、彩票和收藏等内容。按玩家目标选择这些机制，避免因为看到新选项就改变经营方向。

开新档时用 `game_difficulty` 核对难度差异，再用 `game_perks` 核对剩余点数、槽位、互斥关系和已选特质。自动售卖、可用水管、简易反应堆等特质会改变开局可用的设施。特质面板会分页，操作时按显示名称和控件 ID 选中。

后期从高科技走私渠道取得思维重编程器 `mind_reprogrammer` 后，可用相容电子材料充能。打开设备，从 `game_perks.reprogrammer` 核对已有特质、可添加或移除的特质、点数与冷却，再用 `reprogram_perk` 提交当前可用选项。

## 周转与扩张

- 用可用现金预留近期要付的租金、许可费、还款和下一轮必要投入。批发按批追踪实际回款、剩余货与损失。看整批回本时，从该批已实现收入扣掉整批采购成本，混合成交只计该批商品对应的款项。
- 用实际成交和销售速度决定进货量。行情预告用于备货，采购和出售前重读生效时间、实际价格和买家预算。估算新设备或固定服务的收益时，观察多个营业周期，比较相对原做法多赚多少，再扣新增租金、电力、耗材等开支。比较升级方案时也考虑人情的其他用途。若货卖得比产得慢，先消化存货或调低产量。

若目标是取得店铺产权，读 `game_finances.property` 的当前买断价和贷款预览。用首付加各期还款算出贷款总支出，再和买断价比较，同时考虑等候期间的租金、房价变化和付款后的周转金。通过房东或贷款人的原版对话接受报价，随后核对付款、产权标记和抵押剩余期数。晨报租金提醒与产权状态冲突时，以财务面板为准。买断和还清抵押可触发带继续选项的结局，用 `game_menu` 确认是否达成。总结的资金与净值序列可用 `game_finances {"includeHistory":true}` 读取。
